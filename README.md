# 小店日常：餐廳大作戰

單檔 Three.js 3D 餐廳經營遊戲原型。

## 開始遊玩

需要 Python 3。在此目錄執行：

```powershell
python -m http.server 8765
```

開啟 <http://127.0.0.1:8765/>。Three.js 由 jsDelivr 載入，遊玩時需要網路連線。

## 操作

- `W A S D`：在餐廳內移動
- `E`：依位置接單、廚房取餐、送餐、收款、收桌或帶位

在 2 分 30 秒內服務客人，挑戰營收 `$240` 和 4 張訂單目標。
